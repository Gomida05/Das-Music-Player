<h2>Overview</h2>
<p>Das-Music-Player is an Android music player designed to elevate your music listening experience with its seamless playback and user-friendly interface.</p>
<p><strong>Why Das-Music-Player?</strong></p>
<p>This project aims to deliver a robust and engaging solution for mobile music consumption. The core features include:</p>
<ul>
<li>🎶 <strong>Seamless Music Playback:</strong> Enjoy smooth audio playback with intuitive controls for an uninterrupted experience.</li>
<li>📚 <strong>Intuitive Navigation:</strong> Effortlessly manage your music library with a well-structured and user-friendly interface.</li>
<li>🎨 <strong>Customizable UI:</strong> Adapt to light and dark modes with a dynamic theme that enhances accessibility.</li>
<li>🔔 <strong>Real-time Notifications:</strong> Stay informed about playback status through engaging foreground notifications.</li>
<li>🎧 <strong>Efficient Media Management:</strong> Integrate seamlessly with Android's media session framework for effective audio focus handling.</li>
<li>🛠️ <strong>Robust Architecture:</strong> Built with Kotlin and Jetpack Compose, ensuring maintainability and scalability for future enhancements.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul>
<li><strong>Programming Language:</strong> Kotlin</li>
<li><strong>Package Manager:</strong> Gradle</li>
</ul>
<h3>Installation</h3>
<p>Build Das-Music-Player from the source and install dependencies:</p>
<ol>
<li>
<p><strong>Clone the repository:</strong></p>
<pre><code>❯ git clone https://github.com/Gomida05/Das-Music-Player
</code></pre>
</li>
<li>
<p><strong>Navigate to the project directory:</strong></p>
<pre><code>❯ cd Das-Music-Player
</code></pre>
</li>
<li>
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://kotlinlang.org/">gradle</a>:</strong></p>
<pre><code>❯ gradle build
</code></pre>
<h3>Usage</h3>
<p>Run the project with:</p>
<p><strong>Using <a href="https://kotlinlang.org/">gradle</a>:</strong></p>
<pre><code >gradle run
</code></pre>
<h3>Testing</h3>
<p>Das-music-player uses the {<strong>test_framework</strong>} test framework. Run the test suite with:</p>
<p><strong>Using <a href="https://kotlinlang.org/">gradle</a>:</strong></p>
<pre><code>gradle test
</code></pre>
